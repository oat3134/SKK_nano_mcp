# SKK_nano_mcp

เมื่อเลือก **menu0** โปรแกรมจะเข้าสู่โหมด **Calibration Sensor** สำหรับปรับค่ากลางของเซ็นเซอร์ให้เหมาะกับพื้นสนามจริง โดยสามารถเลือกได้ 2 โหมด คือ **NORMAL, FRONT**

โหมด **NORMAL** ใช้สำหรับตรวจสอบค่าที่อ่านได้จากเซ็นเซอร์ด้านหน้าและด้านหลังบนหน้าจอ OLED เพื่อใช้เช็กการทำงานของเซ็นเซอร์ก่อนเริ่มทดลอง

โหมด **FRONT** ใช้สำหรับคาลิเบตเซ็นเซอร์ด้านหน้า ระหว่างการคาลิเบต หุ่นยนต์จะหมุนซ้าย–ขวาเพื่อให้เซ็นเซอร์แต่ละตัวได้อ่านค่าจากทั้ง **พื้นดำและพื้นขาว** จากนั้นโปรแกรมจะเก็บค่า **MIN** และ **MAX** ของเซ็นเซอร์แต่ละตัว แล้วนำมาคำนวณค่ากลางเพื่อใช้เป็น **Threshold**

เมื่อคาลิเบตเสร็จ ค่า Threshold จะถูกบันทึกลงใน **EEPROM** ทำให้ค่าที่คาลิเบตไว้ยังคงอยู่แม้ปิดเครื่องหรือรีเซตบอร์ด และสามารถนำกลับมาใช้ได้อัตโนมัติเมื่อเปิดเครื่องครั้งถัดไป

### คำสั่งสำหรับควบคุมหุ่นยนต์

```cpp
P(ความเร็ว);
```

เดินหน้าตามเส้นจนตรวจพบเส้นตัด แล้วหยุด

```cpp
PT(ความเร็ว, เวลา);
```

เดินหน้าตามเส้นตามระยะเวลาที่กำหนด แล้วหยุด
หน่วยเวลาเป็น **มิลลิวินาที (ms)** เช่น `PT(100,1000);` เท่ากับ 1 วินาที

```cpp
PB(ความเร็ว);
```

ถอยหลังตามเส้นจนตรวจพบเส้นตัด แล้วหยุด

```cpp
PBT(ความเร็ว, เวลา);
```

ถอยหลังตามเส้นตามระยะเวลาที่กำหนด แล้วหยุด

```cpp
L(ความเร็ว);
```

หมุนเลี้ยวซ้ายโดยใช้เซ็นเซอร์ช่วยตรวจจับตำแหน่งของเส้น

```cpp
R(ความเร็ว);
```

หมุนเลี้ยวขวาโดยใช้เซ็นเซอร์ช่วยตรวจจับตำแหน่งของเส้น

ตัวอย่างการเขียน Mission:

```cpp
P(100);
R(100);
P(100);
L(100);
PT(100,1000);
```

ความหมายคือ หุ่นยนต์เดินหน้าจนเจอเส้น → เลี้ยวขวา → เดินหน้าจนเจอเส้น → เลี้ยวซ้าย → เดินหน้าต่อเป็นเวลา 1 วินาทีแล้วหยุด

**หมายเหตุ:** ใน library ปัจจุบันชื่อคำสั่งถอยหลังคือ `PB()` และ `PBT()` ไม่ใช่ `B()` และ `BT()` ครับ.
